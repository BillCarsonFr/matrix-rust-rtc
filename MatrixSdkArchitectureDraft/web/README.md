# matrix-rtc-web — uniffi npm bindings + demo webapp

The uniffi-generated npm package for the draft crate, plus a demo webapp and
the acceptance test suite. Bindings are generated by
[uniffi-bindgen-react-native](https://github.com/jhugman/uniffi-bindgen-react-native)
(wasm target), so this is the **same API** Swift/Kotlin get.

```sh
npm install
npm run ubrn:web   # build the crate for wasm32 + generate TS bindings
npm run dev        # demo webapp on vite
npm test           # acceptance tests (vitest)
```

## Status: tests fail on purpose

The Rust crate is a skeleton — every method is `todo!()`, so each test dies
with a wasm panic (`RuntimeError: unreachable`) at the first `todo!()` it
reaches. `test/participation.test.ts` defines the expected behavior of
`ParticipationManager` end to end (inject events through the TS
`MockMatrixDriver`, assert memberships/connections/keys/status and the
outbound Matrix traffic): it is the harness for implementing the `todo!()`s —
make the tests pass one by one.

## Layout

| path | what |
|---|---|
| `ubrn.config.yaml` | ubrn config: crate at `..`, feature `uniffi` |
| `src/generated/` | **generated** TS bindings + wasm-bindgen output (`npm run ubrn:web`) |
| `src/index.web.ts` | **generated** entrypoint (not used by vite — see `src/wasmLoader.ts`) |
| `rust_modules/wasm/` | **generated** wasm shim crate (our crate + ubrn runtime), fully ignored |
| `Cargo.patch.toml` | merged into the shim's Cargo.toml by ubrn (`manifestPatchFile`) — carries the wasm-bindgen pin |
| `src/wasmLoader.ts` | vite-friendly wasm init (`?url` import instead of direct `.wasm`) |
| `src/mockDriver.ts` | `MatrixDriverCallback` implemented in TS + inbound event fabrication |
| `src/app.ts`, `index.html` | demo: tiles from memberships, connections/key-map/status panels, inject buttons |
| `test/participation.test.ts` | the acceptance tests |

## Gotchas

- **wasm-bindgen pin**: wasm-bindgen's macro crate and CLI must match
  *exactly* (unstable schema), and ubrn bundles its CLI half at 0.2.100
  while the generated shim declares `wasm-bindgen = "*"`. `Cargo.patch.toml`
  pins the crate side to `=0.2.100` via ubrn's `manifestPatchFile`, so the
  generated crate needs no manual fixup and stays untracked. Bump the pin
  together with ubrn.
- **uniffi version**: the crate pins `uniffi = "=0.31.2"` to match
  ubrn 0.31.0-5. Upgrading ubrn means bumping the pin.
- The wire shapes fabricated in `src/mockDriver.ts` are the tests' single
  source of truth for event JSON — if the implementation settles on different
  field names, adjust them there, not in every test.
